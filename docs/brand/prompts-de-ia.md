# Prompts de IA para Afiliados — appMila

> Prompts prontos para gerar copy, anúncios, roteiros e estratégia em minutos. Cole em qualquer IA (ChatGPT, Claude, Gemini). **Sempre revise**: não invente preço/condição e siga o [tom de voz](tom-de-voz.md). v1 (jun/2026).

## Como usar
1. Copie o prompt.
2. Troque os campos `[entre colchetes]`.
3. Revise: preço/condição corretos? Tom direto e honesto? Sem promessa garantida?

### Contexto base (cole no início de qualquer prompt)
```
Você é um copywriter de resposta direta. Produto: appMila — app que transforma VOZ em tarefa/demanda organizada, para EMPRESAS e FAMÍLIAS (web + computador + celular; pt/en/es). Diferencial: capturar tarefas por voz, em segundos, sem digitar. Promessa: "nunca mais perca uma demanda". Tom: direto, prático, humano, conclusão primeiro, sem floreio, sem promessa de resultado garantido, sem número inventado. Público: [empresa | uso pessoal/família | afiliados].
```

---

## 1. Anúncio Meta/Instagram (uso pessoal/família)
```
[contexto base, público = família]
Escreva 5 variações de anúncio para Reels/Stories (gancho nos 2 primeiros segundos + corpo + CTA). Dor: carga mental de lembrar tudo da casa e da rotina; mãos ocupadas (cozinha, carro, filhos). Benefício: falar a tarefa e ela já fica organizada; dividir com a família. CTA: começar grátis. Tom direto e humano, pt-BR. Liste o gancho separado do corpo.
```

## 2. Anúncio Google Search (uso empresa)
```
[contexto base, público = empresa]
Crie 8 títulos (até 30 caracteres) e 4 descrições (até 90 caracteres) para Google Ads, foco em gestores/donos de PME que perdem tarefas combinadas em reuniões. Inclua o diferencial "por voz" e o uso para equipe. Sem superlativos proibidos. pt-BR.
```

## 3. Roteiro de vídeo curto (TikTok/Reels)
```
[contexto base, público = [empresa|família]]
Escreva um roteiro de 20–30s em 1ª pessoa (UGC, sem cara de anúncio): cena de abertura (problema real), demonstração de falar a tarefa, alívio/resultado, CTA. Indique falas + o que aparece na tela. pt-BR, tom natural.
```

## 4. Carrossel educativo (Instagram)
```
[contexto base]
Crie um carrossel de 7 slides: slide 1 gancho, slides 2–5 conteúdo útil sobre organização/produtividade (sem vender ainda), slide 6 apresenta o appMila como solução por voz, slide 7 CTA. Texto de cada slide curto. pt-BR.
```

## 5. E-mail / mensagem para a lista
```
[contexto base]
Escreva um e-mail curto (assunto + corpo) recomendando o appMila para [empresários | famílias]. Estrutura: dor → história rápida → solução (voz) → CTA com meu link de afiliado [LINK]. Sem promessa de resultado garantido. pt-BR.
```

## 6. Bio / link na bio
```
[contexto base]
Crie 5 frases curtas (até 120 caracteres) para bio/CTA de link, vendendo o appMila por voz para [público]. pt-BR.
```

## 7. Recrutamento de outros afiliados (para quem monta rede)
```
[contexto base, público = afiliados]
Escreva 3 mensagens curtas convidando afiliados/gestores de tráfego a promover o appMila. Ângulos: (a) renda recorrente que acumula; (b) 50% de comissão no lançamento (junho e julho/2026; volta a 25% em agosto — urgência); (c) é SaaS, reembolso baixo. Honesto, sem "renda garantida". pt-BR.
```

## 8. Resposta a objeções (DM/comentário)
```
[contexto base]
Liste as 6 objeções mais comuns de quem hesita em assinar o appMila e uma resposta curta, honesta e direta para cada. pt-BR.
```

## 9. Variação por idioma (internacional)
```
[contexto base, público = empresa]
Traduza e adapte (não literal) este anúncio para inglês (EUA) e espanhol (Espanha), respeitando o tom e expressões locais: "[cole o anúncio]". Para a Espanha, use español de España.
```

## 10. Plano de conteúdo (semana)
```
[contexto base]
Monte um calendário de 7 dias de conteúdo (Reels/posts) para promover o appMila para [público], variando dor, demonstração, prova, bastidor e CTA. Para cada dia: formato, gancho e ideia central. pt-BR.
```

---

**Lembrete:** todo material precisa respeitar as políticas de Google/Meta/TikTok e o tom de voz. Use sempre o **seu link de afiliado** da Hotmart. Preços e condições: confirme os valores oficiais vigentes antes de publicar.
