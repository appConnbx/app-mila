# @mila/supabase

Camada de acesso a dados compartilhada.

Conteúdo previsto:
- `src/database.types.ts` — tipos TypeScript **gerados** do banco (`pnpm db:types`). Não editar à mão.
- `src/client.ts` — fábrica de clientes Supabase (browser, server, mobile).
- `src/index.ts` — exports públicos.

> Gerado na Etapa 4 (interface web). Por ora, o que existe de concreto é o schema em `supabase/migrations/`.
